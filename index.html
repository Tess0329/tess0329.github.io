StreamPhone PC 프로그램

휴대폰을 PC 스트림덱으로 씁니다. Windows 10·11용 무료 프로그램입니다.

설치 파일을 내려받는 중입니다. 다시 내려받기
이 페이지는 PC에서 여세요.
PC 브라우저 주소창에 streamphone.github.io를 입력하세요.
  1. 내려받은 파일을 실행해 설치합니다.
  2. StreamPhone에서 "연결 시작"을 누릅니다.
  3. 휴대폰 앱에서 "QR 코드 스캔"을 누르고 PC 화면의 QR을 찍습니다.
PC와 휴대폰을 같은 공유기에 연결해 주세요.
문제가 있나요?
  • 브라우저가 "일반적으로 다운로드되지 않는 파일"이라고 하면 유지를 누릅니다.
  • "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다.
  • 휴대폰이 연결되지 않으면 Windows 설정 → 네트워크에서 집 네트워크(Wi-Fi 또는 유선)를 개인 네트워크로 바꿉니다.
  • 공유기가 없거나 Wi-Fi로 연결되지 않으면 휴대폰을 USB 케이블로 PC에 꽂고 휴대폰 설정에서 USB 테더링을 켠 뒤 QR을 스캔합니다.
  • 설치 없이 쓰려면 압축 파일을 풀어 StreamPhone.exe를 실행합니다(자동 업데이트 안 됨).
